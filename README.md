# SeatSwapConnect 🚆

## 📌 About the Project
SeatSwapConnect is a seat swapping management system that allows users to view available seats and request seat exchanges with other users.

The project aims to make the seat swapping process simple, organized, and user-friendly.

## 🎯 Objectives
- Display available seats.
- Allow users to create seat swap requests.
- Enable users to accept or reject swap requests.
- Manage seat swapping activities efficiently.
- Provide a simple and user-friendly interface.

## 🛠️ Technologies Used
- Java
- HTML
- CSS
- JavaScript
- MySQL
- Maven

## ✨ Features
- User Login Interface
- Dashboard
- Available Seats Display
- Seat Search and Filter
- Create Seat Swap Requests
- Accept or Reject Requests
- Seat Status Management

## 🖥️ Project Modules
1. User Management
2. Seat Management
3. Seat Swap Request Management
4. Swap Approval and Rejection
5. Dashboard

## ⚙️ How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database.
4. Update the database connection settings.
5. Build the project using Maven.
6. Run the Java application.
7. Open `frontend/index.html` in a browser to view the frontend.
